About this room

This is a shared lab room, not a private consultation. There are no accounts or saved conversations.

The server includes a sender ID in each broadcast but does not tell this browser its own ID. Messages keep their original text and the same alignment; “sent by you” cannot be identified reliably.

Times show when this browser received a message, using your device clock. They are not server timestamps.
